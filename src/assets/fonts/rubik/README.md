# Rubik

These unmodified WOFF2 files are Rubik v31, regular 400, normal style. They preserve the six subsets served by the previous Google Fonts request.

- Source CSS: https://fonts.googleapis.com/css2?family=Rubik&display=swap
- Retrieved: 2026-11-10, using a Chromium user agent.
- License: [SIL Open Font License 1.1](LICENSE), from [google/fonts](https://github.com/google/fonts/blob/096e136d61e4e0cf9aff11d38eb2cc73c07381b1/ofl/rubik/OFL.txt).

The CSS uses local URLs and unicode ranges so each browser downloads the subsets it needs. Both the font files and license are included in the npm package.
